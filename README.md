# Customer Event Detection ML Solution

A hands-on, portfolio-scale project building an end-to-end synthetic customer-event
anomaly detection platform: Databricks/PySpark, Apache Airflow, MLflow, Docker, and
GitHub Actions.

**Status:** In progress. See [docs/project-status.md](docs/project-status.md) for what's
actually implemented vs. designed vs. pending.

This is a learning project using entirely synthetic data. It is not a production
fraud/AML system and makes no regulatory claims.
